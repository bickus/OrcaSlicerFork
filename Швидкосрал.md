# Summary of changes made in the Швидкосрал-Edition #
- **BIC-5 – Customizable objects print order.** Adds a dedicated reorder mode so users can click objects on the active plate and assign the exact intra-layer sequence they want. See PR https://github.com/bickus/OrcaSlicerFork/pull/1.
- **BIC-6 – Profile renaming.** Introduces rename for printer and material profiles. Rename moves the underlying preset files, updates IDs, and propagates the change through compatible printers, materials, and physical printer bindings. History of renames is preserved so when an old project is opened which references a renamed profile - a user gets an option to update the reference in the project file. See PR https://github.com/bickus/OrcaSlicerFork/pull/2.
- **BIC-8 – Bridge infill line width controls.** Adds separate line-width parameters for bridge infill and internal bridge infill in Quality -> Line Width so users can tune these flows independently. See PR https://github.com/bickus/OrcaSlicerFork/pull/4.
- **BIC-10 – Granular bridge acceleration and jerk.** Lets users dial different acceleration and jerk values for external and internal bridges so overhangs stay stable without slowing solid infill. See PR https://github.com/bickus/OrcaSlicerFork/pull/5.
- 🐋 **BIC-11 – Move in Orca's Instances.** Restores the instance add/remove/fill UX so users can duplicate models as lightweight instances again while keeping the custom intra-layer ordering from BIC-5 working for both clones and instances. See PR https://github.com/bickus/OrcaSlicerFork/pull/6 (adapted from Orca PR https://github.com/OrcaSlicer/OrcaSlicer/pull/6237).
- **BIC-12 – Improved seam placement on unsupported edges.** Adds a Seam to Overhang Distance guard in Quality -> Overhangs so seams stay a configurable distance away from the start of bridges and steep overhangs when possible. See PR https://github.com/bickus/OrcaSlicerFork/pull/7.
- **BIC-14 – Bridge density to 180%.** Lets users push external and internal bridge density up to 180% for stronger, tighter bridging when needed. See PR https://github.com/bickus/OrcaSlicerFork/pull/9.
- **BIC-XX – Custom Print Order bug fixes.** Fixed issues where clicking objects in reorder mode would just select them instead of assigning print order. Ensured proper instance-plate registration for both newly created instances and instances loaded from existing projects. See PR https://github.com/bickus/OrcaSlicerFork/pull/11.
- **BIC-XX – Filename template + preview stability.** Fixed regression from the instance ordering refactor that immediately invalidated sliced previews after hitting Print/Export and left `filename_format` placeholders (like `{print_time}` or `{filament_vendor[initial_tool]}`) unprocessed.
- **BIC-XX – Klipper cruise ratio control.** Adds a printer-level `klipper_cruise_ratio` option under Motion ability -> Advanced (hidden unless the flavor is Klipper), persists it through presets/3MFs, emits `SET_VELOCITY_LIMIT ... MINIMUM_CRUISE_RATIO` once per print, and forwards the value into the preview `TimeMachine` for upcoming "actual speed" work. Implementation notes live in `doc/klipper_actual_speed/01_printer_setting.md`. https://github.com/bickus/OrcaSlicerFork/pull/13
  - 🔴 **Bugfix: Dirty indicators for new Klipper option.** Fixed UI to properly show the "modified" state for `klipper_cruise_ratio` when changed, even when the parent preset lacks this option. Updated preset diff logic and field decoration for scalar printer settings.
- **BIC-XX – Klipper actual-speed preview.** Adds “Actual speed” as a first-class preview mode, colors both extrusions and travels using the planner’s entry/exit/peak velocities, updates the sequential marker to show achievable speed next to the requested `F`, and documents the pipeline in `doc/klipper_actual_speed/implementation/03_preview_pipeline.md`. https://github.com/bickus/OrcaSlicerFork/pull/13
  - 🔴 **Error: Layer Time preview split into fake segments.** Restored per-layer duration values for segmented preview moves so Layer Time / Layer Time (log) overlays stay flat across each layer.
  - 🔴 **Error: Arrow navigation jumped through tiny segments.** Reworked the moves slider so every preview except Actual Speed walks whole G-code lines again, while Actual Speed still drills down into per-segment chunks.
  - 🔴 **Error: Actual Speed details leaked into other tabs.** Limited the segmented slider and tooltip copy to the Actual Speed legend so other previews respect per-layer navigation and keep their original tooltips.
